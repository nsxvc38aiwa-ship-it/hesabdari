   راهنمای نصب برنامه حسابداری روی اندروید
═══════════════════════════════════════════

این برنامه به صورت Progressive Web App (PWA) ساخته شده
و می‌توانید آن را مثل یک اپ واقعی روی گوشی اندروید نصب کنید.

────────────────────────────
روش ۱: نصب مستقیم از مرورگر (ساده‌ترین)
────────────────────────────
1. همه فایل‌های داخل این پوشه را روی گوشی یا یک هاست (مثل GitHub Pages، Netlify و ...) قرار دهید.
2. با مرورگر Chrome روی اندروید آدرس برنامه را باز کنید.
3. منوی Chrome (سه نقطه) را بزنید.
4. گزینه «Add to Home screen» یا «نصب برنامه» / «Install app» را انتخاب کنید.
5. برنامه روی صفحه اصلی گوشی شما ظاهر می‌شود و مثل اپ عادی باز می‌شود.
6. حتی بدون اینترنت هم کار می‌کند (اطلاعات در خود گوشی ذخیره می‌شود).

────────────────────────────
روش ۲: ساخت APK واقعی (اختیاری)
────────────────────────────
اگر می‌خواهید یک فایل .apk داشته باشید:

الف) با سایت PWA Builder (پیشنهادی و رایگان):
   1. بروید به: https://www.pwabuilder.com
   2. آدرس آنلاین برنامه را وارد کنید (باید روی اینترنت باشد).
   3. گزینه Package → Android را بزنید.
   4. APK را دانلود و نصب کنید.

ب) با Capacitor (برای توسعه‌دهندگان):
   - نیاز به Node.js دارد.
   - دستورات: npm create @capacitor/app → اضافه کردن پلتفرم android → ساخت APK.

────────────────────────────
نکات مهم
────────────────────────────
• داده‌ها در خود مرورگر/اپ (localStorage) ذخیره می‌شوند.
• برای پشتیبان‌گیری از دکمه «پشتیبانی» داخل برنامه استفاده کنید.
• پوشه پشتیبانی را یک‌بار انتخاب کنید تا بک‌آپ‌ها آنجا ذخیره شوند.
• برای بهترین تجربه از Chrome یا Edge استفاده کنید.
